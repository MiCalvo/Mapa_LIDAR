# data/

Carpeta de datos locales. **Git ignora todo su contenido** salvo este fichero: la app la rellena al usarla.
*Local data folder. Git ignores everything here except this file; the app fills it as you use it.*

| Carpeta | Contenido |
| --- | --- |
| `zonas/<zona>/` | Terreno procesado (`*.terreno.json`, `*.mdt.bin`, `*.mds.bin`), nubes `*.copc.laz` y `zona.json` |
| `entrada/` | LAZ/LAS descargados, antes de procesar |
| `catalogos/` | Listados de descarga en caché (30 días) |
| `ortofotos/` | Ortofotos PNOA en caché |
| `archivo/` | Lo que quieras guardar fuera de la app |
